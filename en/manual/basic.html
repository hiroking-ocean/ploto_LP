How to Use Basic Operations

This section explains common screen operations and how to save/manage files in Ploto.

1. Startup Screen

When you launch Ploto, a start popup will first appear to create or open projects.

Creating a New Project

Clicking the 'Create New Project' button opens a new empty project so you can start managing tasks right away.

Opening Existing Files

Clicking the 'Open Local File' button opens a file selection dialog to load and resume editing a .ploto file saved on your PC.

Take the interactive tour

If this is your first time with Ploto, start with the 'Take the interactive tour' button. Using a sample schedule, the app guides you step by step so you learn the basics by actually operating the screen. Three courses are available: Gantt chart (about 4 min), Kanban (about 6 min) and Notes (about 5 min). Starting a course creates a new practice project, so your own files are not affected. You can quit at any point and start over later from 'Start Tutorial' in the 'Help' menu.

Recently Opened Projects

Projects you have previously opened in Ploto are listed. You can quickly open them with a single click without searching for the file path.

2. File & Help Menu

From the menu on the left side of the top header, you can manage project files and view various information.

File Menu

The 'File' menu allows you to perform the following:
• New: Create a new project file.
• Open: Select and load a project file (.ploto) from your PC.
• Save: Overwrite and save the current project.
• Save As: Save the project under a new file name.
• Excel Export / Print [PRO]: Export Gantt charts or task lists as Excel or PDF (Pro features).

Help Menu

The 'Help' menu allows you to perform the following:
• Start Tutorial: Learn the basic flow by working through the actual app screens. Three courses are available — Gantt chart, Kanban, and Notes — and you can restart them at any time.
• Manual: Open this manual page.
• Changelog: View the app update history.
• License: View license information.
• Language: Switch the app language (Japanese, English, German, French, Korean).

3. Sidebar Features

By clicking the icons on the left sidebar, you can display panels for switching project views, searching tasks, managing milestones, and adjusting settings.

Sidebar Panels (3 Types)

The main sidebar menus are as follows:

  • List: Add or switch between project views, including Gantt charts, Kanban boards, priority matrices, member-specific tasks, and whiteboards.
  • Task Search: Type in a task name to search for tasks within the project by keywords.
  • Milestones: Manage and check lists of important milestones set in the project.
  • Settings: Configure application settings.

4. Header Controls

From the buttons on the top right, you can perform quick operations and adjust settings.

Undo / Redo

Using the arrow icons (or shortcuts Ctrl+Z / Ctrl+Y), you can revert or redo your recent actions.

Manual Save

Click the floppy disk icon to immediately save your current changes manually (the app autosaves, but you can also save manually at any time).

Theme Switcher

Click the moon/sun icon to toggle between light and dark mode.
