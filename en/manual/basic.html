How to Use Basic Operations

This section explains common screen operations and how to save/manage files in Ploto.

  • Basic Operations
  • Gantt Chart
  • Kanban Board
  • Notes
  • Whiteboard
  • Priority Matrix

1. Startup Screen

When you launch Ploto, a start popup will first appear to create or open projects.

Creating a New Project

Clicking the 'Create New Project' button opens a new empty project so you can start managing tasks right away.

Opening Existing Files

Clicking the 'Open Local File' button opens a file selection dialog to load and resume editing a .ploto file saved on your PC.

Import from Excel

The 'Import from Excel' button creates a new project and imports a schedule or WBS from Excel. You can check the content in a preview before importing, and reassign any columns that could not be detected automatically.

Take the interactive tour

If this is your first time with Ploto, start with the 'Take the interactive tour' button. Using a sample schedule, the app guides you step by step so you learn the basics by actually operating the screen. Five courses are available: Gantt chart (about 4 min), Kanban (about 6 min), Notes (about 5 min), Cost (about 5 min) and Whiteboard (about 6 min). Starting a course creates a new practice project, so your own files are not affected. You can quit at any point and start over later from 'Start the tutorial' in the 'Help' menu. Pro features such as Kanban, Notes, Cost, and Whiteboard can be tried hands-on in the tutorial, even in the free version. Saving a practice project with added views such as Kanban does require Pro, however.

Recently Opened Projects

Projects you have previously opened in Ploto are listed. You can quickly open them with a single click without searching for the file path.

2. File & Help Menu

From the menu on the left side of the top header, you can manage project files and view various information.

File Menu

The 'File' menu allows you to perform the following:
• New: Create a new project file.
• Open: Select and load a project file (.ploto) from your PC. Recently opened files can also be chosen here.
• Save: Overwrite and save the current project.
• Save As: Save the project under a new file name.
• Import from Excel: Import a schedule or WBS from Excel as tasks.
• Import from Template: Add an exported template (.ploto-pack) to the current file (importing Kanban workflows is a Pro feature).
• Export WBS (Excel): Export a WBS for submission as an Excel file.
• Print / Export to PDF: Print the Gantt chart or save it as a PDF or image. Detailed settings such as choosing tasks or adding columns are Pro features.
• Save as Template: Export projects and Kanban workflows as a reusable template (Pro feature).

Help Menu

The 'Help' menu allows you to perform the following:
• Start the tutorial: Learn the basic flow by working through the actual app screens. Five courses are available — Gantt chart, Kanban, Notes, Cost, and Whiteboard — and you can restart them at any time. Courses on Pro features can be tried in the free version too.
• Manual: Open this manual page.
• Changelog: View the app update history.
• Privacy Policy: See how your data is handled.
• Technical Information: Open documentation you can use when applying to your IT or security department.
• Feedback & bug reports: Send us your comments or report a problem.
• License: Compare the free and Pro versions, purchase, or register a serial code.
• Language: Switch the app language (Japanese, English, German, French, Korean, Spanish, Portuguese).

3. Sidebar Features

Click the icons on the far left of the screen to open the panels for your views, task search, the AI terminal, plans, and project settings.

Sidebar Panels (5 Types)

The main sidebar menus are as follows:

  • Projects & Views:Add or switch between views: Gantt charts, Kanban boards, whiteboards, notes, priority matrices, and member tasks. Views can be reordered by dragging. Creating any view other than a Gantt chart is a Pro feature.
  • Search Tasks:Type in a task name to search for tasks within the project by keywords.
  • AI / Terminal:Run an AI CLI such as Claude, Codex, or OpenCode in the terminal to read and edit the Gantt charts, tasks, and dependencies of the open project. It is a one-time purchase separate from Pro, with a trial limited by number of operations. Fees for the AI service itself are separate.
  • Plans:Save the plan at key milestones and overlay it on the Gantt chart to compare with the current schedule (Pro feature).
  • Project Settings:Configure auto scheduling, working days, holidays, the fiscal year, chart display, the cost currency, and more for each project.

4. Header Controls

From the buttons on the top right, you can perform quick operations and adjust settings.

Undo / Redo

Using the arrow icons (or shortcuts Ctrl+Z / Ctrl+Y), you can revert or redo your recent actions.

Save

Click the floppy disk icon (or press Ctrl+S) to save your current changes to the file. Your work is not saved to the file automatically. A new project does not remain on your PC until you save it, so choose a location and save it as a .ploto file. If you try to exit without saving, a confirmation appears.

Theme Switcher

Click the moon/sun icon to toggle between light and dark mode.
