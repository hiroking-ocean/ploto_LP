    언제 시작해서 언제 끝나는가. 무엇이 끝나야 시작할 수 있는가. 간트 차트가 비추는 것은 시간축으로 자른 하나의 단면입니다.

    두 축으로 무엇부터 할지 정한다

    우선순위를 '높음·중간·낮음'만으로 정하면 모든 작업이 '높음'이 되기 쉽습니다. 얼마나 급한가, 그리고 정말 중요한가. 두 가지를 나누어 생각하면 작업 사이의 차이가 드러납니다.

    • 긴급도×중요도로 플롯한다 작업마다 긴급도와 중요도를 생각해 평면 위에 플롯합니다. '급하니까 중요하다'고 한데 묶지 않고, 두 판단을 하나의 위치로 남길 수 있습니다.
    • 작업끼리 위치로 비교한다 놓인 위치에서 우선순위 점수가 자동으로 계산됩니다. 모든 작업을 최우선으로 두는 대신 평면 위의 차이로 무엇부터 할지 비교할 수 있습니다.
    • 급하지 않은 중요한 일을 놓치지 않는다 마감 순서에서는 묻히는 일도 '중요하지만 급하지 않은' 영역에 남습니다. 눈앞의 급한 일에 쫓겨도 계속 미루고 있는 일을 놓치지 않습니다.

    마지막으로 전체를 한 캔버스에서 본다

    지금까지 일정·상태·맥락·우선순위를 담아 온 작업을 마지막에는 하나의 캔버스에 펼칩니다. 정해진 격자에 맞추는 대신 작업을 움직이고, 관계를 그리고, 필요한 집계를 더합니다. 위치와 연결을 통해 전체를 파악하는 화이트보드입니다.

    • 일의 전체 모습을 자유롭게 그린다 작업뿐 아니라 도형, 텍스트, 메모를 원하는 곳에 배치할 수 있습니다. 테두리와 선으로 관계를 덧그려 표의 나열만으로는 보이지 않던 묶음과 흐름을 하나의 캔버스에 나타낼 수 있습니다.
    • 살아 있는 작업을 캔버스에 놓는다 다른 보기에서 다뤄 온 같은 작업을 캔버스에도 배치할 수 있습니다. 진행률·기한·담당자의 변화가 그대로 반영되므로 다시 붙이거나 고쳐 쓸 필요가 없습니다.
    • 보고 싶은 작업을 연결해 집계한다 진행률 등의 합계를 보여 주는 작은 집계 패널(위젯)에 작업을 화살표로 연결할 수 있습니다. 연결된 작업만 집계되므로 보고 싶은 작업 묶음을 숫자로 확인하고 다음 판단에 활용할 수 있습니다.

주요 기능은 계속 무료, 필요한 만큼만 한 번 결제로.

일반적인 프로젝트 관리 서비스는 사용자 수만큼 매달 비용이 들고, 쓰는 동안 계속 청구됩니다. Ploto는 간트 차트, 우선순위 매트릭스, 노트 등 일상과 업무 일정 관리에 필요한 주요 기능을 기간 제한 없이 무료로 제공합니다. 더 많은 칸반 보드와 화이트보드, 기준선, Excel / PDF 내보내기 등 고급 기능이 필요할 때만 한 번 결제하는 Pro를 추가하면 됩니다. Pro에는 월 사용료나 연 사용료가 없으며 Microsoft Store 또는 웹(Stripe)에서 구매할 수 있습니다.

데이터 관리와 보안에 대하여

프로젝트 데이터는 사용자 PC의 파일로 저장됩니다. 개인 PC에서도, 클라우드 도구 이용이 제한된 직장에서도 똑같이 사용할 수 있습니다. 조직에 도입할 경우의 가능 여부는 각 조직의 규정에 따라 확인해 주세요.

🔒

프로젝트 데이터를 PC에 저장

프로젝트 데이터는 사용자 PC의 .ploto 파일에 저장됩니다. Ploto는 프로젝트 데이터를 외부 서버로 자동 전송하지 않습니다. 파일 보관과 공유 방식은 이용 환경의 규정에 맞게 관리할 수 있습니다.

🏪

Microsoft Store에서 배포

Ploto는 Microsoft Store를 통해 배포됩니다. Store 페이지에서 게시자와 제품 정보를 확인하여 도입 검토 자료로 활용할 수 있습니다.
