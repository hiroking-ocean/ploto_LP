작업은 하나, 보는 방식은 여섯 가지.

Ploto는 같은 작업을 목적에 맞는 화면으로 바꿔 보여줄 뿐입니다. 어느 화면에서 고쳐도 내용은 같은 한 건이므로, 옮겨 적거나 대조할 필요가 없습니다.

이 한 건이 아래 모든 화면에 그대로 나타납니다.

등록은 한 건뿐
메인 페이지 구현
7/7 → 7/12 진행률 40%
  • 간트 차트(공정표) 언제 시작해서 얼마나 걸리는지 정합니다.
  • 칸반 카드를 옮겨 지금 어느 공정에 있는지 바꿉니다.
  • 우선순위 매트릭스 긴급도와 중요도로 배치해 무엇부터 할지 정합니다.
  • 담당자별 작업 누구에게 얼마나 몰려 있는지 보고 배분을 조정합니다.
  • 노트 정해진 사항과 알게 된 점을 작업별로 남깁니다.
  • 화이트보드 작업을 도형으로 배치해 전체 관계를 그려 공유합니다.

예를 들어 칸반에서 카드를 '구현' 열로 옮기면 그 작업의 공정이 바뀌고, 공정표 목록에도 노트의 ToDo에도 같은 상태가 나타납니다. 뷰를 아무리 늘려도 관리하는 데이터는 하나뿐입니다.

매일의 일정 관리에서 걸리는 부분을 미리 없앱니다

작지만 효과가 큰 기능들을, 따로 손대지 않아도 쓸 수 있게 설계했습니다.

진행 상태를 보여주는 3색 알림

작업 상태를 기한 초과(빨강), 시작 지연(노랑), 순조(초록)의 3가지 색상으로 자동 판정하여 표시합니다. 지연된 작업을 수동 체크 없이 바로 확인할 수 있습니다.

공휴일 및 회사 휴일 반영

회사 고유의 휴일 일정을 등록할 수 있습니다. 주말 및 공휴일의 음영 처리로 실제 근무일수에 맞춘 정확한 일정을 계획할 수 있습니다.

하나만 옮기면 뒤 일정도 따라옵니다

작업을 선으로 연결하고 자동 스케줄링을 켜면, 앞 공정이 밀린 만큼 뒤 일정이 자동으로 이동합니다. 상위 작업의 기간과 진행률은 처음부터 하위 작업에서 자동 계산되므로, 한 곳을 고칠 때마다 표 전체를 손볼 필요가 없습니다.

입력은 한 번, 보는 방식은 여러 가지

같은 작업을 공정표·진행 보드·우선순위·노트로 바꿔 가며 볼 수 있습니다. 시트마다 같은 표를 다시 만들거나 옮겨 적다가 숫자가 어긋나는 일이 없어집니다.

일상과 업무에 필요한 주요 기능은 계속 무료.
더 필요할 때만 한 번 결제하는 Pro.

Ploto는 간트 차트, 우선순위 매트릭스, 노트 등 일상과 업무 일정 관리에 필요한 주요 기능을 기간 제한 없이 무료로 제공합니다. 더 많은 칸반 보드와 화이트보드, 기준선, Excel / PDF 내보내기 등 고급 기능이 필요할 때만 한 번 결제하는 Pro를 추가하면 됩니다. Pro에는 월 사용료나 연 사용료가 없으며 Microsoft Store 또는 웹(Stripe)에서 구매할 수 있습니다.

데이터 관리와 보안에 대하여

클라우드 도구 이용이 제한된 환경에서도 Ploto는 프로젝트 데이터를 PC에 저장하는 방식으로 사용할 수 있습니다. 도입 가능 여부는 각 조직의 규정에 따라 확인해 주세요.

🔒

프로젝트 데이터를 PC에 저장

프로젝트 데이터는 사용자 PC의 .ploto 파일에 저장됩니다. Ploto는 프로젝트 데이터를 외부 서버로 자동 전송하지 않습니다. 파일 보관과 공유 방식은 이용 환경의 규정에 맞게 관리할 수 있습니다.

🏪

Microsoft Store에서 배포

Ploto는 Microsoft Store를 통해 배포됩니다. Store 페이지에서 게시자와 제품 정보를 확인하여 도입 검토 자료로 활용할 수 있습니다.

👤

계정 등록이나 로그인 불필요

이메일 등록, 로그인 또는 조직명 입력이 필요하지 않습니다. 설치 후 계정을 만들지 않고 Ploto 사용을 시작할 수 있습니다.
