기본 조작 사용법

Ploto의 공통 화면 조작 및 파일 저장/관리 방법에 대해 설명합니다.

1. 시작 화면

Ploto를 실행하면 먼저 프로젝트를 생성하거나 열 수 있는 시작 팝업이 표시됩니다.

새 프로젝트 생성

'새 프로젝트 작성' 버튼을 클릭하면 새로운 빈 프로젝트가 열려 즉시 작업을 관리할 수 있습니다.

기존 파일 열기

'로컬 파일 열기' 버튼을 클릭하면 파일 선택 대화상자가 열리고 PC에 저장된 .ploto 파일을 불러와 편집을 재개할 수 있습니다.

튜토리얼로 익히기

Ploto를 처음 사용한다면 '튜토리얼로 익히기' 버튼부터 시작해 보세요. 샘플 공정표를 사용해 화면의 안내에 따라 직접 조작하면서 기본 흐름을 익힐 수 있습니다. 과정은 간트 차트(약 4분), 칸반(약 6분), 노트(약 5분) 세 가지입니다. 시작하면 연습용 프로젝트가 새로 만들어지므로 사용 중인 파일에는 영향을 주지 않습니다. 도중에 그만두어도 나중에 '도움말' 메뉴의 '튜토리얼 시작'에서 언제든 다시 시작할 수 있습니다.

최근에 연 프로젝트

이전에 Ploto에서 열었던 프로젝트가 목록에 표시됩니다. 파일 경로를 찾을 필요 없이 한 번의 클릭으로 빠르게 열 수 있습니다.

2. 파일 및 도움말 메뉴

상단 헤더 왼쪽의 메뉴에서 프로젝트 파일을 관리하고 다양한 정보를 확인할 수 있습니다.

파일 메뉴

'파일' 메뉴에서 다음 작업을 수행할 수 있습니다.
• 새로 만들기: 새로운 프로젝트 파일을 생성합니다.
• 열기: PC에서 프로젝트 파일(.ploto)을 선택하여 불러옵니다.
• 저장: 현재 프로젝트를 덮어쓰고 저장합니다.
• 다른 이름으로 저장: 새로운 파일 이름으로 프로젝트를 저장합니다.
• Excel 출력 / 인쇄 [PRO]: 간트 차트나 작업 목록을 Excel 또는 PDF로 내보냅니다(프로 기능).

도움말 메뉴

'도움말' 메뉴에서 다음 작업을 수행할 수 있습니다.
• 튜토리얼 시작: 실제 앱 화면을 직접 조작하면서 기본 흐름을 익힐 수 있습니다. 간트 차트·칸반·노트 세 가지 과정이 있으며 언제든 다시 시작할 수 있습니다.
• 매뉴얼: 이 매뉴얼 페이지를 엽니다.
• 업데이트 이력: 앱의 업데이트 내역을 확인합니다.
• 라이선스: 라이선스 정보를 확인합니다.
• Language: 앱 표시 언어(일본어, 영어, 독일어, 프랑스어, 한국어)를 전환합니다.

3. 사이드바 기능

왼쪽 사이드바의 아이콘을 클릭하여 프로젝트 보기 전환, 작업 검색, 마일스톤 관리 및 설정 등의 패널을 표시할 수 있습니다.

사이드바 전환 패널 (3종류)

사이드바의 주요 메뉴는 다음과 같습니다.

  • 목록:새 프로젝트, 칸반 보드, 우선순위 매트릭스, 멤버별 작업, 화이트보드 등 다양한 보기 화면을 추가하거나 전환합니다.
  • 작업 검색:작업 이름을 입력하여 프로젝트 내 작업을 키워드로 검색합니다.
  • 마일스톤:프로젝트에 설정된 중요한 마일스톤 목록을 관리하고 확인합니다.
  • 설정:애플리케이션 설정을 변경합니다.

4. 헤더 컨트롤

우측 상단의 버튼들을 통해 빠른 조작 및 설정 변경이 가능합니다.

실행 취소 / 다시 실행 (Undo / Redo)

화살표 아이콘(또는 단축키 Ctrl+Z / Ctrl+Y)을 사용하여 최근 작업을 취소하거나 다시 실행할 수 있습니다.

수동 저장

디스켓 아이콘을 클릭하여 현재 변경 사항을 즉시 수동으로 저장합니다(앱에서 자동 저장을 지원하지만 언제든지 수동 저장도 가능합니다).

테마 전환

달/태양 아이콘을 클릭하여 라이트 모드와 다크 모드 간을 전환합니다.
