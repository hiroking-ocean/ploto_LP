1. 제품·문서 정보

본 문서는 Windows용 프로젝트 관리 애플리케이션 Ploto(이하 「본 앱」)에 대한 정보시스템 부서용 기술 정보입니다. 기업·단체의 앱 도입 심사에 이 페이지의 URL 또는 인쇄·PDF로 저장한 문서를 사용할 수 있습니다.

  • 제품명: Ploto
  • 지원 OS: Windows 10·Windows 11
  • 배포처: Microsoft Store
  • Microsoft Store 제품 ID: 9N4NJNMT2B77
  • 스토어 표시 게시자·제공자: hiroki.lab(개인 개발자)
  • 공식 사이트: https://ploto-app.com/
  • 문의처: hiroki.lab@outlook.com

본 앱을 업무 데이터에 사용할 수 있는지는 데이터의 기밀 등급, 단말·저장 위치의 접근 통제, 백업 및 조직의 앱 사용 기준을 고려하여 이용 조직이 최종적으로 판단해 주십시오.

2. 배포·실행 방식·권한

본 앱은 Rust, Tauri 및 Windows WebView2를 사용한 데스크톱 앱으로, Microsoft Store를 통해 MSIX로 배포·업데이트됩니다. 일반 실행 시 관리자 권한으로의 상승을 요구하지 않습니다.

MSIX 매니페스트에서는 데스크톱 앱으로 동작하기 위해 runFullTrust를 선언합니다. 이는 로그인한 사용자와 동일한 권한으로 동작한다는 의미이며, 관리자 권한을 자동으로 부여하는 것은 아닙니다. 본 앱은 Windows 서비스, 시작 프로그램 항목 또는 예약 작업을 만들지 않습니다.

AI 터미널을 사용하는 경우, 본 앱은 화면에 터미널을 표시할 때에만 로그인한 사용자 권한으로 PowerShell, Git Bash 또는 WSL을 자식 프로세스로 실행합니다. 내장 PowerShell은 해당 프로세스에 한해 -ExecutionPolicy Bypass를 지정해 실행하며, 단말·사용자의 실행 정책은 변경하지 않습니다(그룹 정책으로 설정한 실행 정책이 이 지정보다 우선합니다). 또한 AI 클라이언트가 Ploto에 연결하기 위한 실행 별칭 ploto-mcp.exe가 패키지에 포함되어 있습니다. 이는 AI 클라이언트가 실행하는 연결 전용 모드로, 화면이 없으며 Ploto 본체로 요청을 중계하기만 합니다.

3. Microsoft Defender·앱 제어 관련 주의사항

Microsoft Store에서 인증·배포된 앱이라도 조직의 단말에서는 Microsoft Defender 또는 애플리케이션 제어 설정에 따라 설치, 실행 또는 파일 저장이 차단될 수 있습니다. 본 앱은 Rust와 Tauri로 구현한 네이티브 실행 파일을 포함합니다. 이러한 구성의 앱은 배포 직후처럼 실행 실적(prevalence)이 적은 시기에 휴리스틱 탐지나 실적 기반 차단의 대상이 되기 쉬운 경향이 있습니다. 스토어 인증이 조직에서 설정한 이러한 제어를 면제해 주지는 않습니다.

예상되는 상황:

  • 백신의 휴리스틱 오탐: 클라우드 기반 머신러닝 판정으로 새 실행 파일이 Wacatac, Wacapew 등 일반적인 탐지 이름으로 격리되는 경우가 있습니다. 보안 인텔리전스 업데이트 후 해소되기도 합니다.
  • 공격 표면 감소(ASR) 규칙: 「실적, 사용 기간 또는 신뢰할 수 있는 목록 조건을 충족하지 않는 한 실행 파일 실행 차단」을 사용하도록 설정한 경우, 갓 공개된 버전이 차단될 수 있습니다.
  • 제어된 폴더 액세스: 문서, 바탕 화면 등 보호된 폴더에 대한 쓰기가 거부되어 .ploto 파일 저장 오류로 나타날 수 있습니다.
  • WDAC·AppLocker: 서명자 또는 패키지를 허용하지 않은 경우 MSIX 패키지가 아예 실행되지 않습니다.
  • SmartScreen: Microsoft Store를 통한 설치에서는 일반적으로 발생하지 않지만, 조직의 정책 설정에 따라 경고가 표시될 수 있습니다.

PackageFullName과 설치 경로는 버전마다 변경됩니다. 애플리케이션 제어 허용 규칙에는 경로가 아니라 위의 패키지 이름, PFN 및 게시자 정보를 사용하십시오.

조직에서 허용을 검토하는 경우:

  • WDAC·AppLocker: 설치된 패키지 또는 MSIX를 참조하여 Publisher와 Package name이 본 앱과 일치하는 패키지 규칙을 조직의 애플리케이션 제어 기준에 따라 만드십시오. 업데이트를 허용할 버전 범위도 조직의 변경 관리 정책에 따라 설정하십시오.
  • Microsoft Defender·ASR: 탐지 또는 차단이 발생하면 탐지 이름, 대상 파일, 입수 경로, 패키지 서명 및 관리 콘솔 기록을 확인하고 조직의 정해진 절차에 따라 대응하십시오. 보호 기능을 변경하거나 예외를 설정해야 한다고 판단한 경우 보안 관리자의 승인을 받아 본 앱에 한정된 최소 범위와 필요한 기간으로 제한하십시오.
  • 제어된 폴더 액세스: 저장이 거부되면 먼저 조직에서 허용한 저장 위치를 사용하십시오. 본 앱을 허용 목록에 등록해야 하는 경우 Microsoft Store에서 받은 패키지인지와 서명을 확인한 뒤 조직의 승인 절차를 따르십시오.
  • 오탐 신고: 탐지가 잘못되었다고 판단되면 Microsoft 샘플 제출 양식으로 신고할 수 있습니다. 탐지 이름, Defender 버전 및 본 앱의 버전을 아래 문의처로 알려 주시면 제공자 측에서도 신고합니다.

본 앱은 Windows 서비스, 시작 프로그램 항목 및 예약 작업을 만들지 않습니다(제2항 참조). 따라서 탐지가 발생한 경우 휴리스틱에 의한 오탐일 가능성이 높지만, 실제 처리는 조직의 보안 운영 기준에 따라 판단해 주십시오.

4. 파일 접근

기술적으로는 실행 사용자가 접근 권한을 가진 파일을 읽고 쓸 수 있습니다. 제품 기능으로 다루는 대상은 사용자가 열기·저장·가져오기·내보내기 대상으로 선택한 파일, 본 앱의 단말 내 설정·작업 파일, 그리고 동시 편집 방지를 위한 잠금 파일입니다.

단말 내 파일을 전수 조사하는 기능, 임의의 폴더를 지속적으로 감시하는 기능, 프로젝트 파일을 외부로 자동 업로드하는 기능은 없습니다. 저장 위치에 대한 읽기·쓰기 권한은 Windows 및 파일 서버의 접근 통제를 따릅니다.

5. 저장되는 파일과 정보

프로젝트: 사용자가 지정한 위치에 .ploto 파일로 저장합니다. 형식은 표준 SQLite 데이터베이스이며 작업, 담당자 이름, 일정, 할 일, 노트, 화이트보드, 설정 등이 포함됩니다. 템플릿, 가져오기 원본 및 Excel 등의 출력 파일도 사용자가 선택한 위치에서 읽고 씁니다.

작업 사본: 프로젝트를 여는 동안 프로젝트 전체의 작업 사본을 Windows가 관리하는 앱 로컬 데이터 영역에 만듭니다. 정상적으로 닫으면 삭제하며, 비정상 종료로 남은 사본은 다음 실행 시 삭제를 시도합니다.

잠금 파일: 편집 중에는 프로젝트와 같은 위치에 대상 .ploto 파일 이름.lock 파일을 만듭니다. Windows 사용자 이름, 컴퓨터 이름, 프로세스 ID, 시작 시각 및 갱신 시각을 저장하며 정상 종료 시 삭제합니다. 공유 폴더에서는 해당 위치에 접근할 수 있는 사용자 또는 관리자가 확인할 수 있습니다.

단말 내 설정: UI 설정, 라이선스 키, 안내 표시 상태, 편집자 설정 등을 Windows가 관리하는 본 앱의 로컬 데이터 영역에 저장합니다. 최근에 연 파일은 %USERPROFILE%\.ploto\recent-files.json에 최대 10건의 경로와 최종 접근 일시를 저장합니다. 일부 보조 설정 파일은 %USERPROFILE%\.ploto에 저장합니다. 프로젝트를 만든 설치본을 판별하기 위한 무작위 식별 값을 저장하는 경우가 있습니다. 이 값에는 OS의 단말 식별 정보나 개인정보가 포함되지 않으며 외부로 전송하지 않습니다.

AI 연동: AI 연동의 동의 상태, 체험판 사용 횟수, AI 터미널 라이선스 코드 및 Store 검증 일시를 앱 로컬 데이터 영역의 ai-access.v1에 Windows DPAPI로 보호하여 저장합니다. AI 연동을 활성화할 때마다 AI 클라이언트용 작업 폴더 %USERPROFILE%\.ploto\ai(WSL 사용 시 %USERPROFILE%\.ploto\ai-wsl도)에 MCP 연결 설정(.mcp.json, opencode.json, .vscode/mcp.json, .cursor/mcp.json, .gemini/settings.json), AI용 설명서(AGENTS.md, CLAUDE.md, GEMINI.md, PLOTO.md, references/) 및 연결용 스크립트(ploto.ps1, ploto.cmd, ploto.sh)를 다시 씁니다. 모두 인증 정보를 포함하지 않습니다. 자세한 내용은 제7항을 참조하십시오.

6. 네트워크 통신과 허용 목록 후보

프로젝트의 작성·편집·저장 및 구매한 라이선스의 검증에 인터넷 연결은 필요하지 않습니다. 앱 내 WebView에는 외부 사이트에 접속하지 않도록 Content Security Policy를 설정하고 있습니다. 외부 페이지는 사용자의 조작에 따라 기본 웹 브라우저 또는 Microsoft Store에서 열립니다.

AI 연동에서 본 앱은 같은 PC 안의 AI 클라이언트로부터의 연결(명명된 파이프를 통한 MCP와 127.0.0.1로의 루프백 HTTP)만 받아들이며, 본 앱 자체가 AI 관련 외부 통신을 하지 않습니다. 연결 방식의 자세한 내용은 제7항을 참조하십시오. AI CLI가 수행하는 AI 서비스와의 통신(각 AI 서비스의 API 엔드포인트 등)은 사용자가 설치한 AI CLI의 사양과 조직의 네트워크 설정에 따릅니다.

조직에서 통신을 제한하는 경우 주요 연결 대상 후보는 apps.microsoft.com(제품·리뷰), buy.stripe.com·checkout.stripe.com(웹 구매), ploto-v2-license-webhook.vercel.app(구매 완료·연결 확인), docs.google.com(선택 양식), ploto-app.com(공식 사이트·매뉴얼·본 문서), hiroking-ocean.github.io(앱 내 매뉴얼·본 문서 링크)입니다. 각 서비스의 CDN, 인증, 글꼴 등 부수 도메인은 각 사업자의 사양에 따릅니다.

Windows Update, Microsoft Store, Windows 오류 보고 등에 의한 OS·플랫폼 통신은 단말 및 조직의 Microsoft 제품 설정을 따릅니다.

7. AI 연동(AI 터미널·MCP)

AI 터미널은 사용자가 이 PC에 설치하고 본인의 구독으로 로그인한 AI CLI(Claude Code, Codex, Gemini CLI, OpenCode, GitHub Copilot 등)가 Ploto에서 열려 있는 프로젝트를 읽고 편집할 수 있게 하는 기능입니다. 본 앱은 AI CLI를 동봉하거나 자동 설치하지 않으며, AI 서비스의 계정이나 API 키도 다루지 않습니다.

연결 방식: AI는 다음 중 한 경로를 통해서만 Ploto를 조작합니다. 두 경로 모두 같은 PC 안의 연결로 한정되며, 네트워크상의 다른 단말에서는 접속할 수 없습니다. AI가 Ploto의 프로젝트 파일이나 데이터베이스에 직접 접근하는 API는 제공하지 않습니다.

  • MCP(주 경로): AI 클라이언트가 MCP 서버로 ploto-mcp.exe --mcp-stdio(MSIX 앱 실행 별칭)를 실행하고 표준 입출력으로 통신합니다. 이 프로세스는 화면이 없는 중계 전용으로, 받은 요청을 Windows 명명된 파이프 \\.\pipe\LOCAL\ploto-mcp-<64자리 식별값>을 통해 실행 중인 Ploto 본체로 전달합니다. 식별값은 사용자 프로필 경로와 앱 식별자에서 도출한 고정값입니다. 파이프는 접근 권한을 생성자(같은 Windows 사용자)로 한정하고, 원격 연결을 거부하며, 같은 이름의 파이프를 먼저 점유하지 못하도록 배타적으로 생성합니다. 토큰은 사용하지 않습니다. 동시 연결은 최대 16개, 요청 1건은 64KiB까지입니다.
  • 터미널 API(예비 경로): MCP 설정을 읽지 않는 AI 클라이언트를 위해 내장 터미널에서 ploto.ps1, ploto.cmd, ploto.sh가 HTTP로 요청을 보냅니다. 대기는 127.0.0.1의 동적 포트에서만 하며 외부 인터페이스에는 공개하지 않습니다. 각 요청에는 무작위 256비트 Bearer 토큰이 필요하며, 토큰은 메모리에만 보관하고 내장 터미널의 환경 변수로만 전달합니다(파일에는 저장하지 않습니다). Host 헤더를 대조하고, 브라우저로부터의 요청(Origin 포함·크로스 사이트)은 거부합니다. 요청 본문은 64KiB까지입니다. 프로젝트 전환·닫기·앱 종료 시 토큰은 무효화됩니다.
  • 공통 제어: 두 경로 모두 Ploto 내부의 동일한 처리를 거치므로 동의 확인, 읽기 전용 시작, 편집 허용, 저장 불가, 체험판 횟수 관리가 똑같이 적용됩니다. 조작은 한 번에 1건씩 처리하며 응답 대기는 30초까지입니다. 임의의 SQL, 파일 조작, 셸 명령을 실행하는 API는 없습니다.
  • 대기 시점: Ploto 화면을 시작하면 두 경로 모두 대기를 시작하지만, 사용자가 동의하기 전까지 프로젝트 조작은 거부합니다. Ploto가 종료되어 있는 동안에도 AI 클라이언트가 실행한 MCP 중계 프로세스는 종료되지 않으며, 요청에는 'Ploto가 실행 중이 아님'을 반환하고 Ploto가 다시 시작되면 재연결합니다. MCP로 Ploto를 실행하거나, 파일을 열거나, 허용 설정을 변경할 수는 없습니다.
  • Windows 방화벽: 수신은 루프백과 명명된 파이프로 한정되므로 인바운드 허용 규칙은 필요하지 않습니다. AI CLI에서 AI 서비스로의 아웃바운드 통신은 AI CLI 측 사양에 따릅니다.

데이터 흐름: AI가 읽은 프로젝트 내용(작업명, 담당자명, 일정, 노트, ToDo, 태그 등)은 AI CLI를 통해 사용자가 선택한 AI 서비스 제공자에게 전송됩니다. 이 전송은 Ploto 제공자의 서버를 거치지 않습니다. 학습 이용, 보존 기간, 처리 지역 등의 처리는 사용자와 AI 서비스 제공자 간의 계약에 따릅니다. 업무 데이터를 다루는 경우에는 조직이 승인한 AI 서비스와 요금제를 사용하도록 사용자에게 안내해 주십시오.

허용과 조작 범위:

  • 처음 터미널을 표시할 때 동의를 요청하며, 허용하기 전까지 프로젝트 조작을 거부합니다. 동의는 단말에 저장되며 이후에는 다시 표시하지 않습니다.
  • AI의 조작은 매번 읽기 전용으로 시작됩니다. 편집은 사용자가 스위치를 켜거나 AI의 편집 허용 요청을 사용자가 승인한 경우에만 가능합니다. 허용은 파일 전환·종료 시 무효화됩니다.
  • AI의 편집은 화면상의 작업 데이터에만 반영되며, AI가 .ploto 파일을 저장할 수는 없습니다. 저장은 사용자가 화면에서 합니다. 편집은 Ploto의 일반적인 실행 취소(Undo)로 되돌릴 수 있습니다.
  • Ploto의 API는 임의의 SQL이나 셸 실행을 받아들이지 않습니다. 다만 내장 터미널은 사용자 권한의 셸이며, 위의 허용은 셸 안에서 AI CLI가 수행하는 파일 조작이나 명령 실행을 제한하지 않습니다. 이러한 조작은 AI CLI의 권한 설정과 사용자의 승인에 따릅니다.
  • 조작 이력은 메서드명과 성공 여부만 화면에 최대 30건 표시하며 파일에는 저장하지 않습니다. 대화 내용, 터미널 출력 및 조작 내용을 Ploto가 저장하거나 전송하지 않습니다.

AI 클라이언트 설정에 대한 기록: 작업 폴더(제5항) 외에, 다음 경우에만 각 AI 클라이언트의 사용자 설정에 Ploto의 MCP 연결 설정과 연결을 안내하는 짧은 설명서(Skill)를 기록합니다. 기록하는 것은 Ploto 항목뿐이며 다른 설정은 변경하지 않습니다.

  • Codex: Codex는 프로젝트 단위 설정을 읽지 않으므로, AI 연동을 활성화할 때마다 %USERPROFILE%\.codex\config.toml(CODEX_HOME 지정 시 그 아래)과 %USERPROFILE%\.agents\skills에 자동 등록합니다.
  • 그 밖의 클라이언트(Claude Code, Cursor, Gemini CLI, Antigravity, OpenCode, VS Code / Copilot): 사용자가 연결 설정 화면에서 등록 버튼을 누른 경우에만 기록합니다. 설정 폴더가 없는 클라이언트에는 기록하지 않으며, Claude Code의 ~/.claude.json은 이미 있는 경우에만 갱신합니다.
  • 기록 대상 경로는 화면에 표시되며, 같은 화면에서 해제할 수 있습니다.

AI에 전달하는 설명서: Ploto는 AI가 본 앱을 올바르게 조작하기 위한 설명서(조작 절차, API 사양, 쓰기 전 확인, 추측으로 편집하지 않을 것, 인증 정보나 DB를 탐색하지 않을 것 등)를 MCP 초기화 응답 및 작업 폴더의 텍스트 파일로 AI에 전달합니다. 설명서는 AI의 동작을 안내하는 것이며, 보안상의 경계는 위의 허용·읽기 전용·저장 불가 구조로 보장합니다. 전문은 별도 페이지 'Ploto가 AI에 전달하는 설명서'에서 확인하고 복사할 수 있습니다.

체험판과 라이선스: 체험판에서는 API/MCP 조작을 합계 60회까지 받아들입니다. 횟수와 라이선스는 단말에서 관리하며, 사용 현황을 Ploto 제공자에게 전송하지 않습니다. Store 버전의 구매 확인은 Microsoft Store의 방식으로 이루어집니다.

조직에서의 비활성화: 시스템 또는 사용자 환경 변수에 PLOTO_DISABLE_AUTOMATION=1을 설정하면 AI 연동 활성화를 거부합니다. 이는 본 앱 내부의 설정이며, 애플리케이션 제어나 조직의 AI 이용 기준을 대신하지 않습니다. AI CLI 자체의 사용 가능 여부는 조직의 단말 관리와 네트워크 제어로 관리해 주십시오.

8. 외부 서비스와 전송 정보

Microsoft: 앱의 배포, 업데이트, 스토어 내 구매, 리뷰 및 OS 진단을 처리합니다. Ploto 제공자는 Partner Center에서 집계된 배포·품질 정보를 확인하는 경우가 있습니다.

Stripe: 사용자가 웹 구매를 시작한 경우 결제 정보, 구매자 이메일 주소, 상품·금액·통화·일시, 연결 정보 및 개인정보 처리방침 제3.2항의 단말 해시를 처리합니다. 카드 번호 등은 Stripe가 직접 처리합니다.

Vercel: Stripe의 구매 완료 정보를 받아 서명된 라이선스 키를 생성합니다. 구매자용 자체 데이터베이스는 두고 있지 않으나 운영 로그가 처리되는 경우가 있습니다.

Resend: 구매자의 이메일 주소로 라이선스 키를 발송하며 수신처, 본문 및 발송 정보를 처리합니다.

Google: 사용자가 선택 양식을 제출한 경우 응답 내용 등을 처리합니다. 공식 사이트에서는 Google Analytics 4와 Google Fonts를 사용합니다. 본 앱 자체에는 Google Analytics를 포함하지 않습니다.

GitHub: GitHub Pages로 공식 사이트, 매뉴얼 및 본 문서를 제공하며 표준적인 접근 정보를 처리하는 경우가 있습니다.

FormSubmit: 공식 사이트의 문의 양식으로 제출된 내용을 Ploto 제공자의 이메일로 전달합니다.

사용자가 선택한 AI 서비스: AI 터미널을 사용한 경우 AI CLI가 프로젝트 내용을 해당 AI 서비스로 전송합니다(제7항). 이는 사용자와 해당 사업자 간의 계약에 근거한 것이며, 해당 사업자는 Ploto 제공자의 수탁자가 아닙니다.

9. 암호화·인증·안전 관리

.ploto, 작업 사본 및 잠금 파일에는 Ploto 자체의 저장 시 암호화를 적용하지 않습니다. 기밀 정보를 다루는 경우 BitLocker·EFS 등의 OS 기능, 저장 위치 ACL, 공유 권한, 백업, 반출 통제 등을 조직 측에서 설정해 주십시오.

Pro 라이선스는 Ed25519 전자 서명을 단말 내에서 검증합니다. 이는 라이선스 키의 정당성을 확인하는 것이며 프로젝트를 암호화하는 기능은 아닙니다. 웹 구매용 결제 정보는 Stripe가 호스팅하는 화면에서 입력하며, 라이선스 발급 Webhook은 Stripe의 서명을 검증한 후 처리합니다. 비밀 키 및 외부 서비스의 API 키는 앱 자체에 포함하지 않습니다.

이용 조직에서는 최소 권한의 Windows 계정, 단말 암호화, 저장 위치 접근 통제, 백업, 악성코드 대책, OS·스토어 앱 업데이트, 외부 양식에 대한 기밀 정보 입력 제한 등을 시행해 주십시오.

10. 제거와 잔존 데이터

Microsoft Store 버전을 제거하면 Windows가 관리하는 본 앱의 로컬 데이터 영역은 일반적으로 삭제됩니다. 반면 사용자가 지정한 저장 위치의 프로젝트, 템플릿, 가져오기 원본, 출력 파일 및 %USERPROFILE%\.ploto(AI용 작업 폴더 ai·ai-wsl 포함)는 삭제되지 않습니다. 완전히 삭제하려면 필요한 백업을 확인한 후 사용자 또는 단말 관리자가 삭제해 주십시오.

AI 연동으로 각 AI 클라이언트의 사용자 설정에 등록한 Ploto의 MCP 설정과 Skill도 제거 시 삭제되지 않습니다. 제거하기 전에 Ploto의 연결 설정 화면에서 해제하거나, config.toml 안의 # >>> ploto MCP >>>부터 # <<< ploto MCP <<<까지의 구역, JSON 설정 안의 ploto 항목, 각 skills 폴더 안의 ploto-control을 삭제해 주십시오.

비정상 종료나 접근 권한 문제로 작업 사본 또는 잠금 파일이 남는 경우가 있습니다. 잠금 파일은 아무도 해당 프로젝트를 편집 중이 아님을 확인한 후 삭제해 주십시오.
