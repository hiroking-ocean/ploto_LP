1. 基本方針

Ploto（以下「本アプリ」）は、Windows 向けのプロジェクト管理アプリです。本アプリの利用にアカウント作成やログインは必要ありません。

プロジェクトは利用者が指定した端末内または共有場所に保存されます。Ploto 独自のクラウド同期機能はなく、利用者が入力したタスク、担当者、日程、ノート、ホワイトボード等のプロジェクト内容を、Ploto 提供者のサーバーへ自動送信する機能はありません。ただし、利用者がAIターミナルを有効にして自分のAIサービスにプロジェクトを読み取らせた場合は、第3.3項のとおり、そのAIサービスへ内容が送信されます。

アプリ本体には、Ploto 独自のアナリティクス、テレメトリ、広告SDK、行動トラッキングまたは外部の自動クラッシュ送信機能を組み込んでいません。

2. 端末内に保存する情報

プロジェクトは .ploto ファイルとして、利用者が選んだ場所に保存します。画面設定、ライセンスキー、最近開いたファイル、案内の表示状態等は端末内に保存します。プロジェクトを開いている間は、安定して編集・保存するため端末内に作業コピーを作成し、正常に閉じたときに削除します。

共有場所で同じプロジェクトを複数人が同時編集することを防ぐため、プロジェクトと同じ場所に一時的なロックファイルを作成します。このファイルには Windows のユーザー名、コンピューター名、プロセスIDおよび時刻が含まれ、正常終了時に削除されます。

.ploto ファイルには Ploto 独自の暗号化を施していません。業務上の機密情報を保存する場合は、端末暗号化、保存先のアクセス権、共有権限およびバックアップを利用組織の規程に従って設定してください。保存場所・ファイル名・削除方法等の詳細は、情報システム部門向け技術情報で確認できます。

3. 外部サービスを利用する場面

通常のプロジェクト作成・編集・保存はオフラインで行えます。次の操作を利用者が選んだ場合、外部サービスが必要な情報を処理します。

3.1. Microsoft Store・Windows

アプリの配布、更新、Store内購入およびレビューは Microsoft Store が処理します。Windows や Microsoft Store は、端末・組織の設定に応じて、インストール情報、クラッシュ情報、OS・端末に関する診断情報等を処理する場合があります。Ploto 提供者は、個人を直接特定しない集計情報を品質改善に利用する場合があります。Microsoft のプライバシーに関する声明 が適用されます。

3.2. Web経由の有料ライセンス購入（Pro・AIターミナル）

Web購入では Stripe が、購入者のメールアドレス、決済手段、購入商品、金額、通貨、日時および接続情報を処理します。カード番号等の機密な決済情報は Stripe が直接処理し、Ploto 提供者のサーバーでは取得・保存しません。

端末紐付けライセンスを発行するため、購入開始時に Windows の発行者向け端末識別値から Ploto 専用の一方向ハッシュを端末内で生成し、Stripe へ送信します。元の端末識別値は送信しません。Vercel 上の処理がライセンスキーを発行し、Resend が購入者のメールアドレスへ送信します。購入後のライセンス確認は端末内で行われます。

Stripe プライバシーポリシー、Vercel Privacy Notice、Resend Privacy Policy がそれぞれ適用されます。

3.3. AIターミナル（AI連携）

AIターミナルは、利用者がこのPCに導入し、自身で契約・サインインしたAI CLI（Claude Code、Codex、Gemini CLI、OpenCode 等）から、Plotoで開いているプロジェクトを読み取り・編集できるようにする機能です。利用者が初回の確認画面で許可するまで、AIからのプロジェクト操作は受け付けません。

AIがプロジェクトを読み取ると、読み取られたタスク名、担当者名、日程、ノート、ToDo、タグ等の内容は、AI CLI を通じて利用者が選んだAIサービスの提供者へ送信され、処理されます。この送信は AI CLI とAIサービスが行うもので、Ploto 提供者のサーバーを経由せず、Ploto 提供者がその内容や会話を受け取ることはありません。送信された情報の取扱い（学習への利用、保存期間、処理地域等）は、利用者とAIサービス提供者との契約および各社のプライバシーポリシーに従います。業務データを扱う場合は、所属組織が承認したAIサービスと契約プランを利用してください。

AI は、MCP（Model Context Protocol）またはこのPC内でのみ使える API を通して Ploto を操作します。いずれの接続もこのPC内に限られ、外部から接続できません。AIからの操作は読み取り専用で始まり、編集には利用者によるスイッチ操作または許可が必要です。AIがプロジェクトファイルを保存することはできず、保存は利用者が Ploto の画面で行います。一方、内蔵ターミナルは Windows のユーザー権限で動作するシェルであり、Ploto の許可設定はそのシェル内でAI CLIが行うファイル操作やコマンド実行を制限しません。これらはAI CLIの設定と利用者の承認に従います。

AI連携のため、端末内に次の情報を保存します：同意状態、体験版の利用回数、AIターミナルのライセンス情報（Windows のデータ保護機能で保護）、およびAI向けの接続設定・説明書（%USERPROFILE%\.ploto\ai）。また、Codex を使う場合は有効化時に、その他のAIクライアントは利用者が登録ボタンを押した場合に、各クライアントの設定フォルダへ Ploto の接続設定と接続用の説明書を書き込みます。これらに認証情報は含みません。AIとの会話内容とターミナルの出力を Ploto が保存・送信することはありません。

Ploto がAIに渡す説明書の内容、保存場所、無効化の方法等の詳細は、情報システム部門向け技術情報で確認できます。

3.4. 問い合わせ・任意のフォーム

利用者が問い合わせメールまたは Google Forms を送信した場合、入力した内容と任意のメールアドレスを、回答、サポート、不具合調査および品質改善のために利用します。本アプリがプロジェクト内容を自動添付・送信することはありません。組織の許可なく秘密情報、個人情報、プロジェクトファイルまたは画面キャプチャを送信しないでください。Google プライバシー ポリシー が適用されます。公式サイトのお問い合わせフォームから送信した会社名、氏名、メールアドレスおよび内容は、FormSubmit を経由して Ploto 提供者のメールに届きます。

3.5. 公式サイトの閲覧

本ポリシーを含む公式サイト ploto-app.com は GitHub Pages で配信します。GitHub が通常のアクセス情報を処理する場合があります。GitHub General Privacy Statement が適用されます。

公式サイトは Google Analytics 4 を利用し、Google Fonts のWebフォントと Microsoft Store のバッジを外部から読み込みます。これに伴い、IPアドレスなどの通常のアクセス情報が Google および Microsoft に送信されます。Google Analytics 4 は Cookie を使用します。公式サイトを ?ga=off 付きで開くと、そのブラウザでは計測タグを読み込まない設定を保存します。?ga=on 付きで開くと解除します。

公式サイトのスクリプトがブラウザに保存するのは、テーマの選択と上記の計測タグの設定です。

4. 利用目的・第三者による処理

Ploto 提供者が購入、問い合わせ、任意フォーム等を通じて受け取る情報は、ライセンスの発行・再送・端末紐付け、不正利用防止、決済・サポート対応、不具合調査、品質改善、会計・税務・紛争対応その他の法令遵守に必要な範囲で利用します。

プロジェクトデータ、購入者情報または問い合わせ情報を販売、貸与、広告配信またはデータブローカーへの提供に利用しません。配布、購入、ライセンス発行、メール送信、フォーム送信およびWeb閲覧のため、必要な範囲で Microsoft、Stripe、Vercel、Resend、Google、GitHub および FormSubmit が情報を処理します。各社の方針に従い、日本国外を含む国・地域で処理または保存される場合があります。

AIターミナルで利用するAIサービスは、利用者自身が選択・契約した事業者であり、Ploto 提供者の委託先ではありません。Ploto 提供者は当該AIサービスへ情報を提供しておらず、その取扱いについては各AIサービスの規約・方針が適用されます。

法令に基づく場合、人の生命・身体・財産の保護に必要な場合、または権利保護・不正防止に必要な場合は、適用法令の範囲で関係機関等へ情報を開示することがあります。

5. 保存期間・削除・確認等の請求

購入・ライセンス情報は、ライセンスの再表示・再送、購入サポート、不正防止、会計・税務その他の法令遵守に必要な期間保持します。問い合わせ・フォーム回答は、回答、調査、品質改善および法令遵守に必要な期間保持します。外部事業者が独自目的で保持する情報の期間は各社の方針に従います。

利用者が保存したプロジェクト等は、利用者が削除するまで残ります。アプリをアンインストールしても、利用者が選択した保存先のファイルと一部の端末内補助ファイルは残ります。完全な削除方法は、情報システム部門向け技術情報を確認してください。

Ploto 提供者が保有する購入者情報、問い合わせ情報等の確認、訂正、利用停止または削除を希望する場合は、下記の連絡先へ請求してください。本人確認のうえ、法令上または取引・ライセンス記録上保持が必要な情報を除き、合理的な範囲で対応します。プロジェクト内容は提供者が保有しないため、提供者側での開示・復元・削除はできません。
