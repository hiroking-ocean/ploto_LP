Como usar as operações básicas

Esta seção explica as operações comuns da tela e como salvar e gerenciar arquivos no Ploto.

  • Gráfico de Gantt

1. Tela inicial

Ao abrir o Ploto, uma janela inicial aparece primeiro para criar ou abrir projetos.

Criar um novo projeto

O botão "Criar novo projeto" abre um projeto vazio para você começar a gerenciar tarefas imediatamente.

Abrir arquivos existentes

O botão "Abrir arquivo local" abre uma caixa de diálogo para escolher um arquivo .ploto salvo no seu PC e continuar a edição.

Importar do Excel

O botão "Importar do Excel" cria um novo projeto e importa um cronograma ou WBS do Excel. Antes de importar, você pode conferir o conteúdo em uma prévia e reatribuir as colunas que não foram detectadas automaticamente.

Fazer o tour interativo

Se é a primeira vez que você usa o Ploto, comece pelo botão "Fazer o tour interativo". Com um cronograma de exemplo, o aplicativo guia você passo a passo para aprender o básico operando a tela. Há cinco cursos: Gráfico de Gantt (cerca de 4 min), Kanban (cerca de 6 min), Notas (cerca de 5 min), Custos (cerca de 5 min) e Quadro branco (cerca de 6 min). Cada curso cria um novo projeto de prática, então seus arquivos não são afetados. Você pode parar a qualquer momento e recomeçar depois em "Iniciar o tutorial" no menu "Ajuda". Recursos Pro como Kanban, Notas, Custos e Quadro branco podem ser experimentados na prática no tutorial, mesmo na versão gratuita. No entanto, salvar um projeto de prática com visualizações adicionadas, como Kanban, exige o Pro.

Projetos abertos recentemente

Os projetos que você abriu antes no Ploto aparecem em uma lista. Você pode abri-los com um único clique, sem procurar o caminho do arquivo.

2. Menus Arquivo e Ajuda

No menu do lado esquerdo do cabeçalho, você gerencia os arquivos do projeto e consulta diversas informações.

Menu Arquivo

O menu "Arquivo" permite realizar as seguintes operações:
• Novo: cria um novo arquivo de projeto.
• Abrir: seleciona e carrega um arquivo de projeto (.ploto) do seu PC. Os arquivos recentes também podem ser escolhidos aqui.
• Salvar: sobrescreve e salva o projeto atual.
• Salvar como: salva o projeto com um novo nome de arquivo.
• Importar do Excel: importa um cronograma ou WBS do Excel como tarefas.
• Importar de modelo: adiciona um modelo exportado (.ploto-pack) ao arquivo atual (importar fluxos Kanban é um recurso Pro).
• Exportar WBS (Excel): exporta um WBS para entrega como arquivo do Excel.
• Imprimir / Exportar para PDF: imprime o gráfico de Gantt ou o salva como PDF ou imagem. Ajustes detalhados, como escolher tarefas ou adicionar colunas, são recursos Pro.
• Salvar como modelo: exporta projetos e fluxos Kanban como modelo reutilizável (recurso Pro).

Menu Ajuda

O menu "Ajuda" permite realizar as seguintes operações:
• Iniciar o tutorial: aprenda o fluxo básico operando as telas reais do aplicativo. Há cinco cursos (gráfico de Gantt, Kanban, Notas, Custos e Quadro branco), que podem ser refeitos a qualquer momento. Os cursos de recursos Pro também podem ser experimentados na versão gratuita.
• Manual: abre esta página do manual.
• Registro de alterações: mostra o histórico de atualizações.
• Política de Privacidade: explica como seus dados são tratados.
• Informações técnicas: abre documentação que pode ser usada em solicitações ao departamento de TI ou de segurança.
• Comentários e erros: envie sua opinião ou informe um problema.
• Licença: compara as versões gratuita e Pro, permite comprar ou registrar um código de série.
• Language: muda o idioma do aplicativo (japonês, inglês, alemão, francês, coreano, espanhol, português).

3. Recursos da barra lateral

Clique nos ícones na extremidade esquerda da tela para abrir os painéis de visualizações, busca de tarefas, terminal de IA, planos e configurações do projeto.

Painéis da barra lateral (5 tipos)

Os principais menus da barra lateral são estes:

  • Projetos e visualizações:Adicione visualizações ou alterne entre elas: gráficos de Gantt, quadros Kanban, quadros brancos, notas, matrizes de prioridade e tarefas dos membros. As visualizações podem ser reordenadas arrastando. Criar qualquer visualização que não seja um gráfico de Gantt é um recurso Pro.
  • Buscar tarefas:Digite o nome de uma tarefa para procurar tarefas do projeto por palavras-chave.
  • IA / Terminal:Execute no terminal uma CLI de IA como Claude, Codex ou OpenCode para ler e editar os gráficos de Gantt, as tarefas e as dependências do projeto aberto. É uma compra única separada do Pro, com um teste limitado por número de operações. As taxas do próprio serviço de IA são à parte.
  • Planos:Salva o plano em marcos importantes e o sobrepõe ao gráfico de Gantt para comparar com o cronograma atual (recurso Pro).
  • Configurações do projeto:Configure, para cada projeto, o agendamento automático, os dias úteis, os feriados, o ano fiscal, a exibição do gráfico, a moeda dos custos e mais.

4. Controles do cabeçalho

Com os botões no canto superior direito, você faz operações rápidas e ajusta configurações.

Desfazer / Refazer

Com os ícones de seta (ou os atalhos Ctrl+Z / Ctrl+Y), você reverte ou refaz suas ações mais recentes.

Salvar

Clique no ícone de disquete (ou pressione Ctrl+S) para salvar as alterações no arquivo. Seu trabalho não é salvo automaticamente no arquivo. Um projeto novo não fica no seu PC até ser salvo, então escolha um local e salve-o como arquivo .ploto. Se você tentar sair sem salvar, aparece uma confirmação.

Alternar tema

Clique no ícone de lua/sol para alternar entre o modo claro e o escuro.
